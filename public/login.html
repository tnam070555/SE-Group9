Trang đang mở sai cách

Bạn đang mở thẳng file từ ổ đĩa nên trang không gọi được API. Hãy chạy server rồi mở qua địa chỉ web:

  1. Mở terminal tại thư mục dự án
  2. Chạy npm start
  3. Mở http://localhost:5000/admin

Trên Windows nếu npm start báo lỗi "running scripts is disabled", gõ npm.cmd start.
